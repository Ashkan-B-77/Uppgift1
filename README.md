# To-Do Application

This is a simple web application built with HTML, CSS and JS for a school assignment.

## How to use

- **Add a task**
― Type in the input and click *Add Task* to add it to the list of tasks.
- **Mark as done**
― Click on a task to mark it as completed.
- **Mark as not done**
― Click on a completed task to switch it to unfinished.
- **Delete a task**
― Click on the trash icon to remove the task from the list.
